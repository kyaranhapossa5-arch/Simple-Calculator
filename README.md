# 🧮 Simple Calculator

A sleek, lightweight, and fully functional web-based calculator designed for quick daily arithmetic operations. Built with clean code and responsive design to work smoothly across both desktop and mobile screens.

[🚀 **Try the Live Calculator Here**](https://kyaranhapossa5-arch.github.io/Simple-Calculator/)

---

## 📖 Description

This project is a web-based calculator built to provide a clean, intuitive, and distraction-free user experience for essential daily calculations. 

The goal of this project was to construct a robust functional application using core web technologies, focusing on:
* **User Experience (UX):** A clean interface with instant visual feedback on button presses.
* **Accuracy & Logic:** Handling sequential operations, clear functions, and mathematical edge cases reliably.
* **Accessibility & Responsiveness:** Ensuring fluid scaling across mobile, tablet, and desktop viewports.

---

## ✨ Features

* **Basic Arithmetic Operations:** Addition, subtraction, multiplication, and division.
* **Responsive Layout:** Optimized interface for mobile phones, tablets, and desktop browsers.
* **Keyboard Support:** Inputs can be entered using standard keyboard keys or on-screen buttons.
* **Error Handling:** Graceful feedback for edge cases like division by zero.

---

## 🛠️ Built With

* **HTML5:** Semantic structure and layout.
* **CSS3:** Custom layout styling, color schemes, and button animations.
* **JavaScript (ES6):** Core calculation logic and DOM manipulation.
