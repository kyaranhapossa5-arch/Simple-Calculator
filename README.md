# 🧮 Functional Calculator

A sleek, lightweight, and fully functional web-based calculator designed for quick daily arithmetic operations. Built with clean code and responsive design to work smoothly across both desktop and mobile screens.

[🚀 **Live Demo & Interactive App**](https://kyaranhapossa5arch.github.io/Simple-Calculator/)

---

## ✨ Features

* **Basic Arithmetic Operations:** Addition, subtraction, multiplication, and division.
* **Responsive Layout:** Optimized interface for mobile phones, tablets, and desktop browsers.
* **Keyboard Support:** Inputs can be entered using standard keyboard keys or on-screen buttons.
* **Error Handling:** Graceful feedback for edge cases like division by zero.

---

## 🛠️ Built With

* **HTML5:** Semantic structure and layout.
* **CSS3:** Custom layout styling, color schemes, and button animations.
* **JavaScript (ES6):** Core calculation logic and DOM manipulation.
